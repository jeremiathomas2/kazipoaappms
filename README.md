# Kazipoa — Smart Service Marketplace System

Kazipoa is a robust, modern marketplace platform designed to bridge the gap between service professionals and clients. Built with a focus on real-time tracking, automated scheduling, and a highly customizable user experience, Kazipoa streamlines service delivery across various industries like cleaning, plumbing, electrical work, and more.

## 🚀 Core Features

- **Dashboard Overview**: Real-time business intelligence with live stats, booking activity charts, and a dynamic activity feed.
- **KaziLive Monitoring**: An advanced real-time session tracking system with live timers, countdowns, and instant communication hubs.
- **Advanced Professionals Directory**: Managed list of verified pros with dual-view support (Grid/List), intelligent search, and multi-criteria filtering.
- **Automated Scheduling**: A smart calendar system that auto-generates service sessions from existing bookings.
- **Real-time Chat**: Secure, instant messaging between administrators, professionals, and clients with automated status updates.
- **Full Customization**: A comprehensive settings engine allowing real-time branding changes, animation control, and theme persistence (Dark/Light mode).

## 🛠️ Technology Stack

- **Framework**: Laravel 11.x
- **Frontend**: Blade Templating, Vanilla JS, Font Awesome 6.5 (Advanced Icons)
- **Database**: SQLite (Default) / MySQL Compatible
- **Styling**: Custom CSS3 Variable-based Design System
- **State Management**: Browser localStorage for appearance and UI persistence

## 🎨 Customizable Appearance

Kazipoa features a unique real-time customization engine:
- **Interface Colors**: Adjust Sidebar, Header, Footer, and Accent colors via integrated pickers.
- **Animation Control**: Fine-tune transition speeds and card hover behaviors.
- **Dynamic Themes**: Fully persistent Light and Dark modes with zero-flicker page loads.
